# Hifz

A calm Qur'an memorization (hifz) companion — track what's memorized, what
you're working on, and what needs revision. Sister app to Daily Tilawah.

See `CLAUDE.md` for the architecture and build order.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build (dist/)
npm run icons    # regenerate public/icons/ from assets/icon-master.svg
```
